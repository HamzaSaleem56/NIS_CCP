# GitHub repository

The assignment source is published at:

**https://github.com/Global-Tech-hub/ccp-nis-fall-2026-vrfc**

Visibility is **private**. The repository owner must invite the instructor and any group members who need repository access through GitHub **Settings → Collaborators**. A private repository URL can return a not-found page for anyone without permission.

Clone with authorized GitHub access:

```bash
git clone https://github.com/Global-Tech-hub/ccp-nis-fall-2026-vrfc.git
cd ccp-nis-fall-2026-vrfc
python3 -m unittest discover -s tests -v
```

The repository contains the comment-free source, tests, data, actual results, report files, independent reviews, and submission instructions. No credentials or machine-local environment files are required.
