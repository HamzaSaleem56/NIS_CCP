Lock a message with two classical ciphers.

A Vigenère keyword shifts every letter, then a 2×2 Hill matrix mixes the letters in pairs. Everything runs in your browser; nothing you type is sent anywhere.

What happened, step by step

  1. Clean the text

    Only the letters A–Z are kept, in capitals.

  2. Stage I: Vigenère

    Each letter moves forward by the matching keyword letter (A = 0, B = 1, …). The keyword repeats.

  3. Stage II: Hill, two letters at a time

    Each pair becomes a column of two numbers and is multiplied by the key matrix, mod 26. Pick a pair to see the maths.

  4. Result

    The message has an odd number of letters, so the last one skips the Hill stage and keeps only its Vigenère shift.

Frequency attack

Uses only the ciphertext. It finds each row of the inverse Hill matrix by how English-like the letters look, then each Vigenère shift by comparing letter counts with normal English.

Known-plaintext attack

The attacker also knows how the message starts. Subtracting pairs cancels the keyword, and a little matrix algebra gives both keys. Odd-length keywords need more known letters than even ones.

Not every 4 letters make a Hill key.

The matrix has to be undone during decryption, which only works when its determinant is odd and not 13. Check a key, or pick one that works.

How VHC works, in one page.

The design

VHC (Vigenère–Hill Cascade) chains two ciphers taught in the course. Stage I is a Vigenère cipher with a keyword of at least 10 letters. Stage II is a 2×2 Hill cipher with its own 4-letter key. Decryption runs the same stages backwards with the inverse matrix. If a message has an odd number of letters, the last letter skips the Hill stage, so nothing is padded and decryption is always exact.

Why it can be broken

Both stages are linear, so together they act like one Hill cipher plus an offset that repeats every L/2 pairs (or every L pairs when the keyword length L is odd). Two consequences:

  • Each row of the inverse matrix can be found on its own, so the attacker checks 42 groups of rows instead of 157,248 matrices.
  • Two known pairs in the same key position have the same offset, so subtracting them removes the keyword completely.

In the project's experiment (20 trials per length), the frequency attack recovered every message of 800 letters or more, and 32 known letters were enough to recover every message.

Run it yourself

The Python version, tests, experiment data and full report are in the repository.

git clone https://github.com/HamzaSaleem56/NIS_CCP.git
cd NIS_CCP
python3 src/cipher.py encrypt --key CRYPTOGRAPHY --hill-key HILL --text "Meet at the library at six pm"
python3 -m unittest discover -s tests -v

Open the repository or read the full report (PDF).
